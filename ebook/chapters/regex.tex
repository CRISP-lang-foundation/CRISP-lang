\section{Regular Expressions}

CRISP includes native Perl-style regular expression support via the Rust \texttt{regex} crate. The \texttt{=~} operator tests for a match, and the \texttt{s///} syntax performs substitution.

\subsection{Match Operator}

The \texttt{=~} match operator returns a boolean in scalar context:

\begin{tcolorbox}[colback=codebg, colframe=darkpurple, colbacktitle=darkpurple, title=\textbf{\textcolor{codegold}{Regex Match}}, fonttitle=\bfseries, sharp corners]
\begin{lstlisting}
let text = "The quick brown fox jumps over the lazy dog";

# Basic match
let result = text =~ /fox/;
say result;  # true

# Match in if condition
if text =~ /quick/ {
    say "Found quick!";
}

# Case-insensitive flag
if text =~ /FOX/i {
    say "Found fox!";
}

# Match against a variable pattern
let pattern = "brown";
if text =~ /pattern/ {
    say "Matched!";
}
\end{lstlisting}
\end{tcolorbox}

\subsection{Global Match}

With the \texttt{g} flag, \texttt{=~} returns an array of all matches:

\begin{tcolorbox}[colback=codebg, colframe=darkpurple, colbacktitle=darkpurple, title=\textbf{\textcolor{codegold}{Global Match}}, fonttitle=\bfseries, sharp corners]
\begin{lstlisting}
let text = "cat dog cat bird cat";

# Find all matches
let matches = text =~ /cat/g;
say matches;  # ["cat", "cat", "cat"]

# Count occurrences
say len(matches);  # 3
\end{lstlisting}
\end{tcolorbox}

\subsection{Substitution}

The \texttt{s///} operator replaces matched text. Use \texttt{g} for global replacement:

\begin{tcolorbox}[colback=codebg, colframe=darkpurple, colbacktitle=darkpurple, title=\textbf{\textcolor{codegold}{Substitution}}, fonttitle=\bfseries, sharp corners]
\begin{lstlisting}
let text = "The quick brown fox";

# Single substitution (first occurrence)
let result = s/fox/cat/;
say result;  # The quick brown cat

# Global substitution
let text2 = "one two one two";
let result2 = s/one/1/g;
say result2;  # 1 two 1 two

# Using the Substitute expression directly
let modified = substitute(text, "brown", "red", false);
say modified;  # The quick red fox
\end{lstlisting}
\end{tcolorbox}

\begin{tcolorbox}[colback=lightlavender, colframe=softvioletdark, title=\textbf{\textcolor{darkpurple}{Design Note: Regex Implementation}}, fonttitle=\bfseries, sharp corners]
Regular expressions in CRISP are powered by the Rust \texttt{regex} crate, which provides:
\begin{itemize}
    \item \textbf{Compile-time optimization:} Patterns are compiled once and cached
    \item \textbf{Unicode support:} Full UTF-8 matching by default
    \item \textbf{Perl-compatible syntax:} Most common Perl regex features are supported
    \item \textbf{Safety:} No catastrophic backtracking — the regex engine uses finite automata
\end{itemize}

The regex is not a first-class type — patterns are passed as strings and compiled at the point of use. Capture groups (\texttt{\$1}, \texttt{\$2}) are not currently implemented as automatic variables but are available through the \texttt{regex\_capture()} function in the standard library.
\end{tcolorbox}
